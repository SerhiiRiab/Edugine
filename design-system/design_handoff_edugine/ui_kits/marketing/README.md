# Marketing UI kit

Recreates the public-facing Edugine surfaces: landing page, login, signup. All use the violet→purple→indigo full-bleed gradient with white type + glass pills.

**Files**
- `index.html` — click-thru of all three screens (toolbar pill at the bottom)
- `Landing.jsx` — hero + supporting "what's inside" rail
- `LoginCard.jsx` — email/password + magic link form
- `SignupCard.jsx` — three-field sign-up form

**Source**: `src/app/page.tsx`, `src/app/(auth)/login/page.tsx`, `src/app/(auth)/signup/page.tsx` in the Edugine repo.
